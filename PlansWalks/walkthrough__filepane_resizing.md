# 実装完了ウォークスルー: ファイルペインの幅調整・トグル表示機能

マウスドラッグによるファイルペイン（サイドバー）の幅調整機能、および表示/非表示（トグル）切り替え機能の実装が正常に完了しました。さらに、テスト環境でのデータ汚染対策およびWailsバインディングモック方式へのテストコード更新も合わせて対応しました。

---

## 1. 変更した主要ファイル

### 1.1. フロントエンド実装

* **[frontend/src/app.tsx](file:///d:/work/pumlv-gui/frontend/src/app.tsx)**
  * **状態管理の追加**: `sidebarWidth` (初期値: `288px`) および `sidebarOpen` (初期値: `true`) を `localStorage` で永続化する形でステートとして定義しました。
  * **ドラッグイベントの処理**: `handleMouseDown` ハンドラーを実装し、マウス移動をグローバルリスナー（`mousemove`, `mouseup`）で追跡することで、境界からマウスが外れてもカクつきのないスムーズなドラッグ（最小 `180px`、最大 `600px`）を実現しました。
  * **リサイザーUIの挿入**: サイドバーとメイン領域の境界に透明なリサイザー用 `div` を配置しました。ホバー時およびアクティブ（ドラッグ）時に、境界線が鮮やかなバイオレット（`bg-violet-500` / `bg-violet-600`）に変化するプレミアムな視覚エフェクトを適用しています。
  * **左右の対称トグルボタン**: 
    - **左側 (ファイルペイン)**: メインヘッダー左端にサイドバーの表示状態をトグルする左サイドバー型アイコンボタン（`title: サイドバーを閉じる/開く`）を新規配置しました。
    - **右側 (ソースペイン)**: 以前は `show source` / `hide source` というテキストボタンだった右側のトグルを、ファイルペインと対称的なデザインの右サイドバー型アイコンボタンに変更してUIを統一しました。ツールチップも日本語化（`title: ソースペインを閉じる/開く`）しています。

### 1.2. テストの修正と追加

* **[frontend/src/app.test.tsx](file:///d:/work/pumlv-gui/frontend/src/app.test.tsx)**
  * **テスト干渉対策**: `beforeEach` で `localStorage.clear()` を実行するようにし、テスト間でトグル状態などの localStorage への書き込みが干渉して他のアサーションが失敗する（テスト汚染）現象を防止しました。
  * **トグル動作のテスト追加**: ボタンクリックによりサイドバーが非表示になり、再度クリックで元に戻る一連の表示切り替えロジックをテストケースとして新規追加しました。
  * **アサーションの更新**: ソースペインのトグル検証にて、ボタンの `textContent` ではなく、新しいツールチップである `title` 属性を検証するようにアサーションを更新しました。
  * **Wailsバインディングのモック追加**: `GetLastFolder`, `SelectFolder`, `OpenFolder` のWails Goバインディング呼び出しをモックし、WebView2環境でなくともテストが正常に通過するように修正しました。
* **[frontend/src/api/files.test.ts](file:///d:/work/pumlv-gui/frontend/src/api/files.test.ts)**
  * 旧 `fetch` API方式のテストから、Wails Go API（`GetFiles`, `GetFileSource`）のモックを使用したテストにリファクタリングしました。
* **[frontend/src/api/events.test.ts](file:///d:/work/pumlv-gui/frontend/src/api/events.test.ts)**
  * 旧 `EventSource` 方式のテストから、Wails Events (`EventsOn`) のモックを使用したテストにリファクタリングしました。また、TypeScriptコンパイル時の未使用変数エラー（`cb`）も合わせて修正しました。
